# Press Agent Communication Plan

## Objectives

- Publish verified project updates.
- Keep public messaging clear and factual.
- Avoid unverified claims.

## Channels

- Discord for community updates.
- Telegram for lightweight broadcast updates.
- X/Twitter for public milestone announcements.

## Message Types

- Build status updates.
- Deployment confirmations.
- Grant or ecosystem updates.
- Security or operations notices.

## Approval Rule

Review public messages before release unless they are low-risk health/status updates.
