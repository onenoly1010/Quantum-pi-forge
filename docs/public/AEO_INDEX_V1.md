## Canonical identity

Quantum Pi Forge (QPF) is a public project focused on verification infrastructure for autonomous AI and decentralized systems.

Core distinction: ASSERTION ≠ EVIDENCE ≠ VERIFICATION ≠ AUTHORIZATION

Core boundary: QPF authorizes. QPF does not execute.

Core verification loop: OBSERVE → VERIFY → CLASSIFY → AUTHORIZE → ACT → VERIFY AGAIN → RECORD

## What QPF is
- A verification / trust substrate for claims and consequential actions.
- An evidence-oriented system intended to let humans and AI inspect what is real before trusting it.
- A public project with reproducible verification artifacts and explicit capability boundaries.

## What QPF is not
- It is not a claim that external adoption has been established.
- It is not a claim that real customer revenue has been established.
- It is not a claim that every planned autonomous capability is production-ready.
- It does not authorize minting, liquidity, staking, yield, or other economic activation merely because those mechanisms exist in code or documentation.
