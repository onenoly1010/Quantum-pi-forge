# Missing Source Notice

The originally planned four-file attestation bundle referenced two source files that were not present in the repository during v0.3.1 preparation:

- 0G_AI_AGENT_INTEGRATIONS.md
- FINAL_SYSTEM_STATUS_ATTESTATION.md

The v0.3.1 bundle therefore does not claim those missing files are included.

Instead, this release binds the attestation documents actually present in the repository at build time.

This preserves audit honesty and avoids placeholder or reconstructed evidence being mislabeled as original source material.
