## Metrics to track
- Verified deployed contracts
- Evidence receipts count
- Build/test verification status
- Public pages live
- GitHub commits, PRs, contributors, stars, forks
- Human onboarding completions
- Controlled mint status
- Participant count
- Independent node/operator count
- Audit status
- Grants submitted / awarded
- Partner conversations / LOIs
- Revenue or licensing activity

## Current rule
No valuation uplift should be externally claimed unless supported by measurable evidence.
