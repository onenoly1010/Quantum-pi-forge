## Purpose
This index gives partners, auditors, grant reviewers, and strategic diligence reviewers a single entry point for Quantum Pi Forge valuation, audit readiness, governance gates, public safety posture, and evidence receipts.

## Reviewer posture
QPF should be reviewed as early-stage sovereign AI and decentralized execution infrastructure. This index does not claim external fair-market valuation. It organizes evidence that may support future valuation, audit, licensing, partnership, or grant review.

## Fast review path
1. Start with the FMV baseline and valuation evidence files.
2. Review the IP asset register and value metrics dashboard.
3. Review the audit readiness package, live evidence addendum, permission map, and threat model.
4. Review governance gate receipts for mint, liquidity, staking, bridge, Guardian authority, and authorization posture.
5. Confirm public pages and disabled financial surfaces match the receipt posture.
