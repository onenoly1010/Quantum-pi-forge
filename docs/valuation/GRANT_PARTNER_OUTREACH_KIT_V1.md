Purpose: prepare a governance/docs-only outreach package for grants, partners, accelerators, auditors, and ecosystem reviewers. All capability claims must derive from the verification status table.

## Allowed

- Grant package drafting
- Partner one-pager
- Audit/reviewer summary
- Evidence and diligence references
- Public-good verification framing

## Forbidden

- Wallet signing
- Token transfer
- Liquidity activation
- Staking activation
- Bridge activation
- Public mint opening
- Private key access

## Activation posture

This lane is opportunity activation only. It does not authorize financial, wallet, mint, staking, liquidity, bridge, or governance execution.
