## Purpose

This supervisor assigns a continuous bounded workflow to local AI so Quantum Pi Forge can test autonomous ecosystem improvement without crossing wallet, signing, funding, deployment, liquidity, or mainnet mutation boundaries.

The objective is to observe whether local AI can continue improving the ecosystem by completing governance, evidence, public review, and sustainability-readiness tasks without stopping until the assigned queue is complete.

## Core Posture

LOCAL-FIRST RESILIENCE + PUBLIC EVIDENCE + FUNDING READINESS + ZERO WALLET RISK

## Autonomous Objective Queue

A. Complete Funding Constraint Resilience Mode v1.
B. Complete and merge Cold Storage Custody Gate v1.
C. Create Public Evidence Mirror / Offline Review Packet.
D. Create Sustainability Readiness Gate v1.
E. Create concise Reviewer/Funder Packet.

## Allowed Autonomous Actions

- Inspect repository state.
- Create local branches.
- Create markdown governance documents.
- Create JSON receipts.
- Create verifier scripts.
- Run local verifiers.
- Commit safe local artifacts.
- Prepare pull request bodies.
- Document remote CI or hosting limitations.
- Produce reviewer and funder packets.

## Blocked Autonomous Actions

- Reading, requesting, storing, or generating seed phrases.
- Reading, requesting, storing, or generating private keys.
- Wallet signing.
- Funding movement.
- Token approvals.
- Bridge actions.
- Contract deployment.
- Liquidity actions.
- RPC mutation.
- Mainnet mutation.
- Any action that bypasses a future explicit operator gate.

## Completion Rule

The local AI workflow is complete only when all A-E objectives have a local artifact, local receipt, verifier, and clean local verification result. Remote CI, Vercel, Cloudflare, or billing-dependent systems are not authoritative blockers when local evidence is complete.
