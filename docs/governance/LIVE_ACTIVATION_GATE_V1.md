# Live Activation Gate v1

**Status:** PROPOSED_ACTIVATION_GATE
**Baseline:** 38fe142 (Spiral Return Field Kit v1)
**Mode:** STAGED_LIVE_ACTIVATION
**Live Execution:** NOT YET AUTHORIZED
**Autonomous Local Orchestration:** AUTHORIZED_FOR_DRY_LOCAL_AND_READ_ONLY_ONLY

## Purpose

This gate opens the live activation lane for Quantum Pi Forge / OINIO without collapsing the safety boundaries that protect the truth surface.

The system may move from mobile field observation toward staged operational activation, but only through bounded, receipt-driven phases.

## Phase 1: Authorized Now

- Autonomous local orchestration.
- Local receipt generation.
- Local evidence indexing.
- Local attestation reconciliation.
- Read-only network checks where safe.
- Status reporting.
- Failure detection.
- Queue preparation for human review.

## Still Blocked

- Private-key access.
- Autonomous wallet actions.
- Autonomous transaction signing.
- Liquidity movement.
- Deployments.
- Treasury routing.
- Automated fee capture.
- Creator payout.
- Live protocol revenue claims.
- Public upload of field attestations without reconciliation gate.
- Any irreversible mainnet mutation without explicit human approval.

## Activation Doctrine

The Forge may become live only by preserving the order:

TRUTH -> TRUST -> CONTROLLED_ACTIVATION -> VERIFIED_OPERATION -> VALUE_FLOW

Autonomy is permitted only where it improves verification, resilience, and continuity without bypassing human authority over irreversible actions.

## Required Before Full Live Execution

- Activation scope receipt.
- Operator approval receipt.
- Key-access policy.
- Transaction signing policy.
- Rollback / halt policy.
- Emergency stop command.
- Live execution verifier.
- Post-activation receipt.

## Final Boundary

This gate opens the activation lane but does not authorize autonomous wallet use, autonomous signing, liquidity movement, deployments, treasury routing, or live revenue claims.
