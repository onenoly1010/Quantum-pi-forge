## 3. Locked economic model

```text
TRUST
  → IDENTIFIABLE AGENT
  → UTILITY
  → REAL ECONOMIC ACTIVITY
  → QPF PARTICIPATION
```

Hard boundary:

> Verification establishes trust. It does not authorize economics.

Product rule:

> QPF does not charge people merely to establish verifiable truth.

### Tier 1 — Core protocol (free)

QPF provides:

- identity (`qpf.identity.verifiable-ai.v1`, `qpfid0:`)
- canonicalization
- evidence binding
- Level 0 verification and receipts
- provenance / inspectability
- `qpfpkg0` packages
- agent trust infrastructure

No protocol toll booth. No fee to exist as a verified identity. No payment required to inspect public evidence.

### Tier 2 — Optional human services (may be paid)

Paid work is **labor around the protocol**, not payment for truth:

- integration and custom deployment
- consulting and evidence-readiness
- enterprise onboarding
- local AI setup, training, support
- professional implementation and SLA

This preserves prior commercial preparation without making “sell one verification” the center of QPF.

If a default public CTA is “pay to verify,” the toll booth has returned.

### Tier 3 — Long-term protocol participation (not live)

When separately designed and authorized, QPF participates in **defined economic events generated by verified agent activity**, for example:

- agent services
- agent marketplaces
- inference or verified work products
- agent-to-agent transactions
- licensed agent capabilities

QPF does **not** take a percentage merely because an INFT agent exists.

The percentage, payer, event, mechanism, and regulatory posture are **not chosen here**.
