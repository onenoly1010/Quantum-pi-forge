# Customer Evidence Matrix v1

| QPF claim | Evidence | Customer benefit | Expected outcome | Acceptance criteria |
| --- | --- | --- | --- | --- |
| QPF publishes a verifiable public deployment. | Cloudflare Pages deployment runs, live `version.json`, and public deployment evidence. | A reviewer can distinguish a deployed release from a repository claim. | A public endpoint and its deployed version can be checked. | Endpoint responds; version/source relationship is recorded. |
| QPF provides reproducible public verification for its own surface. | `scripts/verify-public-portal.mjs`, deployed-addresses page, and verification records. | A reviewer can inspect published contract/deployment facts without relying only on narrative. | A documented verification path with explicit limits. | Commands or public steps run successfully for the stated QPF scope. |
| QPF distinguishes active from inactive protocol features. | Public site status language and deployment verification records. | A customer is less likely to infer unavailable economic functionality. | Clear scope boundaries for technical and commercial discussions. | Documentation labels inactive features and exclusions plainly. |
| QPF can prepare an evidence-readiness package. | Internal service playbook, evidence library, and prior QPF verification practice. | A team receives a structured map of claims, proof, gaps, and next actions. | A bounded delivery packet, not an audit certification. | Scope, evidence items, findings, limitations, and next actions are delivered. |
| QPF can prepare a deployment-transparency baseline. | Internal delivery playbook plus QPF's own public deployment practice. | A team receives a clearer source/deployment/verification story. | A public-safe baseline report with known gaps. | Current references, conflicts, verification steps, and limitations are documented. |

## Claim limits

The last two claims are prepared service capabilities, not proof of completed
third-party engagements. Every client use requires discovery and a human-approved
scope.
