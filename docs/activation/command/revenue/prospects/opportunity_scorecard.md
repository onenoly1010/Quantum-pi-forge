# Opportunity Scorecard

**Purpose:** Rank evidence-backed opportunities without treating discovery as
permission to contact, apply, transact, or alter protocol controls.

## Scoring method

Score each criterion from 0 to 2:

| Criterion | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Primary-source evidence | None | Organization only | Current official program or need |
| Active pathway | None | General interest page | Clear current application, grant, or contact route |
| Capability fit | Weak | Adjacent | Direct match to verification, evidence, or deployment work |
| Near-term value | Speculative | Potential future value | Plausible 30-60 day application or service path |
| Safety and scope | Conflicts with boundaries | Unclear | Services/documentation path with no protocol activation |

**Qualification threshold:** 6/10, with at least 1 point for both
primary-source evidence and active pathway.
