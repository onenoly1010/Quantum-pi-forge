# Active Resonance Worker Monitoring v1

Activation language is operator intent. Receipts are evidence.

This document does not claim autonomous workers are live on mainnet by declaration alone.

A worker is considered active only when local receipts show timestamp, branch, commit, working tree state, observed process state, verification result, and receipt hash.

Allowed: process listing, local health checks, git state capture, npm script inventory, verifier execution when available, and receipt generation.

Not allowed: wallet actions, deploys, token transfers, external posting, cloud dependency assumptions, or claims of funding, authority, custody, or mainnet control without receipt evidence.

Receipt path: receipts/resonance-workers/

A successful receipt proves only that the local environment was observed at the recorded time and produced the recorded result.
