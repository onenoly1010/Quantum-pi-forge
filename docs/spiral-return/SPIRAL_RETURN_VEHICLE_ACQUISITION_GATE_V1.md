## Vehicle Rule

No vehicle is treated as road-trip ready unless it is:

- legally owned or usable
- insured
- registered
- mechanically reliable
- inspected or reasonably checked
- affordable without destroying the emergency buffer
- able to support the intended route
- supported by a return / pause / reroute reserve
