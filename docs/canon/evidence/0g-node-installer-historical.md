# 0G Node Installer Historical Evidence

## Observation

A shell script named `0g.sh` was preserved as historical evidence.

It appears to be a 0G chain node installer script. It installs Go and build dependencies, clones `0glabs/0g-chain`, initializes `0gchaind`, downloads genesis/snapshot files, writes a systemd service named `0g.service`, and attempts to enable/restart that service.

## Boundary

This script is not proof of a currently running 0G node.

This script is not proof of a functional 0G Storage client.

This script must not be executed automatically. It is preserved only as historical install-attempt evidence.

This is a claim, not a fact.
