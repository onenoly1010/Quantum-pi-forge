# Static Review Safety Note

This repository is currently presented for sealed public review.

Reviewer inspection is intended to be static and documentation-first. No reviewer is required or authorized to execute runtime systems, sign transactions, deploy contracts, move tokens, activate staking, trigger governance, activate oracles, or run autonomous agents.

Permitted review activities include:

- reading documentation
- inspecting source files
- comparing claims against tests, hashes, commits, and evidence artifacts
- checking static file structure
- verifying that proof references are complete and internally consistent

Any command shown in reviewer documentation should be treated as optional static inspection unless explicitly marked otherwise.

During this review phase, documentation does not authorize operational expansion.

## Claim Posture Precedence

If older deployment guides, site copy, examples, archived notes, or operational drafts contain active-sounding language, they do not override this sealed review boundary.

During sealed public review, operational-sounding language should be treated as historical, draft, illustrative, archived, or pending verification unless it is directly tied to current evidence and explicitly marked as in-scope.
