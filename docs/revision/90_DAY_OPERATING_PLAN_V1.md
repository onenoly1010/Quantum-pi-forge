# 90-day operating plan

Start: 2026-09-30
End: 2026-12-29
Owner: one person. If a task needs a second person, drop the task.

## Daily cadence (Mon–Fri, 4 hours)

- 90 min outreach (DMs, replies, 0G / grant / AI-launch threads)
- 90 min product (site copy, report template, intake form)
- 60 min delivery or sample report
- 0 min new protocol features

Saturday: one public “claim of the week” post. True, boring, sourced.
Sunday: off.

## Week 1

- [ ] Ship homepage copy from PUBLIC_HOMEPAGE_COPY_V1.md
- [ ] Put $3,500 / $12,000 / $2,000 on /open.html with a payment or invoice path
- [ ] Publish sample report: OINIO bytecode present, pair 0/0, mint not authorized
- [ ] Make a 5-line X bio: “I check public claims about contracts and AI systems. Not an audit.”
- [ ] List 50 names: 0G builders, grant writers, AI-onchain teams

## Week 2–3

- [ ] 10 conversations per week. Script:

  “I write a bounded evidence report: what your public claim proves, what it doesn’t, what is unknown. $3,500. Want me to run one claim free so you see the format?”

- [ ] Give 5 free format demos. Convert 1 to paid even at $1,500.
- [ ] Do not explain the constellation.

## Week 4

- [ ] First invoice sent
- [ ] Report template frozen (sections locked)
- [ ] Intake form: claim text, evidence URLs, deadline, payer email

Gate: if zero conversations happened, the plan failed because of sales avoidance, not product.

## Week 5–8

- [ ] 3 paid reports or 1 launch pack
- [ ] Case study with the buyer’s permission
- [ ] Watch offer only after a report exists
- [ ] Still no mint, no LP, no new repo

## Week 9–12

- [ ] $10,000 cumulative or a written kill decision
- [ ] If revenue exists: build a one-page status dashboard for Watch clients
- [ ] If revenue is zero: freeze Claim Check marketing and spend 30 days only on Offline Dev Guardian as a single installer product, or stop

## Kill criteria

Stop the Claim Check push if all are true on day 90:

- fewer than 20 real conversations
- zero paid invoices
- you spent the quarter writing more governance docs

Then either sell the installer, take a job, or pick a different buyer. Do not start repo number 10.

## Allowed metrics

Track only:

- conversations started
- demos sent
- invoices sent
- cash received
- hours spent on protocol vs sales

Stars, commits, receipts minted, and guardian counts do not count.
