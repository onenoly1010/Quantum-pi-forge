## Stage 1 — Find the first **problem**, not the first “user”

Do **not** open with:

> Do you want to use OINIO?

Open with:

> What repetitive task wastes your time that you wish was easier?

The product attaches to **existing pain**.

| Pain family (examples) | Why it may fit |
| --- | --- |
| Documentation generation / maintenance | High friction, recurring |
| Research synthesis | Large information sets |
| Workflow automation (manual steps) | Repeatable |
| Code / technical assistance | Familiar for Circle 1 devs |
| Verification / “what is true right now” | Aligns with cockpit strength |
| Knowledge organization | Private AI + control |
| Business operations / admin drafts | Non-crypto value |

**Investigator questions (copy):**

1. What do you do every week that feels like a grind?  
2. How long does that usually take?  
3. What have you tried (tools, AI, nothing)?  
4. If one small part got easier this week, which part?
