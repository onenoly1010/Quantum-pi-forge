## 0. Growth model (correct order)

### AI-agent intuition (refined)

Valid idea:

> If AI agents find a tool useful, they can become repeat users through the humans and systems that deploy them.

Catch:

> Today's models do **not** independently choose software, create accounts, or drive adoption. **People** decide what gets integrated into workflows.

**Realistic engine:**

```text
Build something AI likes to use
        ↓
Convince developers / orgs to put it in their AI workflows
        ↓
Those AI systems use it repeatedly
```

**Not realistic as step 1:** market to “everyone” or hope agents self-adopt.

### Human trust first

```text
Human finds value
  → evidence captured
  → community shares
  → more humans test
  → agents automate repeat workflows
  → network effect
```

## 1. Who the first ten are

Not: “How do I get 10,000 users?”

Instead:

```text
Where are the first 10 people who would genuinely miss this
if it disappeared tomorrow?
```

Those ten teach you what to build next.

### Right-fit signal (stronger than generic compliments)

Someone in Pi or 0G (or AI-builder circle) says:

```text
"I used this to solve a real problem, and I'll use it again next week."
```

| Prefer | Avoid as “proof” |
| --- | --- |
| Has the problem this week | Random internet praise |
| Would miss the tool if gone | Architecture tourists |
| Pi / 0G / AI-workflow context | “Cool project” with no task |

## 4. Customer discovery loop (your new protocol)

Same discipline as engineering evidence:

```text
Talk to one potential user
  → Watch them try to accomplish something
  → See where the project genuinely helps
  → Improve that experience (docs/UX only unless install broken)
  → Repeat
```

| Step | Question |
| --- | --- |
| Discovery | What task do you wish AI handled better? |
| Interaction | Can I try one small part with you? |
| Execution | Complete the task |
| Evidence | Before / after / would use again / quote |
| Repeat | What would they miss if it disappeared? |

**Human owns every relationship.** Agents may draft messages, trackers, summaries when asked — no auto-send.
