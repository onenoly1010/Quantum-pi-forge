# Pilot Evidence Loop v1

**Mode:** Proof of value · **not** construction  
**Phase:** 3 — Prove usefulness  
**Companion:** [E1_PRIVATE_AI_OPERATOR_CHECKLIST_V1.md](./E1_PRIVATE_AI_OPERATOR_CHECKLIST_V1.md)  
**Agent posture:** Stand down unless install breaks  

```text
Limiting factor is no longer intelligence or architecture.
Limiting factor is contact with reality.

AI review loops no longer list engineering blockers.
They repeatedly point at the same missing evidence:
  external proof of value

Next artifacts are not:
  PR numbers · commits · architecture docs

Next artifacts are:
  pilot user · task completed · time saved
  repeat usage · testimonial · retention
```

### Front door (user-facing — keep simple)

| Do not lead with | Lead with |
| --- | --- |
| “Sovereign AI ecosystem with post-quantum secure autonomous agents…” | **“A private AI assistant that saves you time on your real work.”** |

The deeper ecosystem stays underneath. Narrow the message; do not pivot the whole project away.

### Next milestone (small — first market signal)

```text
Not: 1,000 users
Not: finish the entire ecosystem

Yes:
  One external person
  completes one meaningful task
  and says they want to repeat it.
```

One such card beats another large technical milestone.

## The loop (one cycle per pilot)

```text
User
  ↓
Problem  (pain this week — not “tour the stack”)
  ↓
OINIO interaction  (E1 min path + one real task)
  ↓
Result  (what was produced)
  ↓
Time saved / value created
  ↓
Would they use again?
```

**Three successful loops** teach more than another large engineering push.

## Target scenarios (planning only — not forecasts)

| Scenario | Rough weight | What it looks like |
| --- | --- | --- |
| **A** Narrow valuable use case | ~50% (target) | “OINIO saves a specific user ~5 hours/week” |
| **B** Impressive ecosystem, niche | ~35% | Strong tech; weak commercial pull |
| **C** Breakout adoption | ~15% | Needs onboarding + pain + network + consistency |

**Target A deliberately.** Do not optimize for C by building more protocols.

- Pain this week (one sentence):

- Meaningful time saved? yes / no / unclear

  >

- Issue 1 → fix (docs/UX only unless install hard-broken):

- No mint / LP / wallet / chain mutation: **confirmed**

### Cohort decision rule

| After 3 cards | Do |
| --- | --- |
| ≥2 “meaningful time saved” + “use again” | Double down on **that** narrow use case (Scenario A) |
| Friction is only install | Fix onboarding docs only |
| Value unclear for all 3 | Change packaging/task — **not** add agents |
| They only want architecture tours | Wrong cohort — re-recruit pain-holders |

## Success quotes worth more than commits

Any of these, from an **external** person, upgrades proof-of-value:

```text
"I used this and it saved me two hours."
"I would use this again next week."
"OINIO saves me about N hours a week on <specific pain>."
```

## Immediate human steps

1. Name 3 pain-holder users (private).  
2. Run E1 + fill one **Evidence Card** each.  
3. Fix only observed struggle points.  
4. After 3 cards: pick the narrow use case that worked — stop expanding surface area.

```text

LOOP: User → Problem → Interaction → Result → Time saved → Use again?
LOCKS: HELD
ENGINEERING: frozen except pilot-blocking install
```
