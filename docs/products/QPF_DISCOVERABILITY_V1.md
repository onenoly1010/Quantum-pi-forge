# QPF Discoverability v1

**Diagnosis (accurate):** The bottleneck is now **discoverability and legibility**, not another draft, pilot brief, or authorization loop.

**Not the default next step:** “Invite friends / force Pilot #001.”  
**Better question:**

> How can Quantum Pi Forge become something someone **discovers on their own** because it solves a problem they **already have**?

That scales. It works while you sleep. It matches self-sustaining better than persuading people into a pilot.

```text
Two stories that drifted apart:

Story 1 — polished internal assets (briefs, funnels, docs, commits)
Story 2 — "earning and self-sustaining"

When you said you hate inviting, friends won't do it, nobody gets it:
  that was the real bottleneck speaking — not a docs bug.

Foundation → Visibility → Usage → Trust → Revenue
Revenue is usually last — not the first external milestone.
```

## Two growth strategies (do not confuse them)

| Recruit / invite | Discover / search |
| --- | --- |
| You persuade someone to try | They already want help |
| Bottleneck: social energy | Bottleneck: **findability + clarity** |
| Pilot #001 as campaign | Page ranks / is linked / is obvious |
| “Will you join my pilot?” | “I found a page that verifies my claim” |

Both can exist. **Discoverability first** reduces dependence on hating outreach.

## Problems people already wake up with

(Not “I want an evidence package.”)

| Human problem (search intent) | What QPF can be for them |
| --- | --- |
| Can someone check this smart contract / deploy? | Independent verification output |
| Is this GitHub repo / project legitimate (on-chain claims)? | Claim vs live state labels |
| Did this deployment actually happen? | Address + code + network checks |
| Can I verify this token/project before I put money/time? | Gated vs live honesty |
| Can I prove this AI/system claim to someone else? | Shareable receipt / certificate |
| Is this admin mint / LP still locked? | Explicit gated / not authorized |

**Under one minute:**

> **Problem:** You’re not sure if a digital system’s claims are real.  
> **Help:** We turn those claims into something you (and others) can check — and we say what we did **not** check.  
> **Start:** Public example on the verify portal · or request a verification.

## Funnel still valid — entry is discovery

```text
Discover (search / link / share)
  → Understand (under 1 minute)
  → Request or self-serve check
  → Deliver (if service)
  → "Helped because ______"
  → Return / refer
  → Pay (later)
```

Climb only with **real entrants**.  
If redesigning discoverability assets for weeks with **zero** public publish → packaging under another name.
