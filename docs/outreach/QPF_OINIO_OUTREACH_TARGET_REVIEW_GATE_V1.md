## Purpose

This gate defines the manual target-review step before any QPF / OINIO outreach is sent. It does not send messages, automate contact, authorize wallet activity, or open public minting.

## Allowed Target Categories

- 0G ecosystem reviewers
- Grant program reviewers
- Infrastructure partners
- Verification / audit partners
- AI + blockchain infrastructure collaborators
- Human-readable trust layer reviewers

## Required Human Review Before Send

Before any outreach is sent, the human operator must approve:

1. The target name or organization.
2. The target category.
3. The final message body.
4. The artifact links included.
5. The outreach channel.
6. The timing of the send.

## Disallowed Automation

This gate does not authorize automatic sending, scraping, mass messaging, wallet connection, signing, transaction broadcast, minting, token transfer, liquidity, staking, or bridge activity.

## Current Message Position

QPF / OINIO may be presented as a sovereign verification and human-readable trust layer. Human Cockpit v1 may be presented as a pipeline-refreshed read-only witness dashboard, not a live controller.

## Current Safety Position

- Public Mint: Not Open
- Controlled Mint: Requires Verification
- Wallet Signing: Disabled
- Token Transfer: Disabled
- Liquidity: Disabled
- Staking: Disabled
- Bridge: Disabled
- Outreach: Manual review only

## Non-Authorization Statement

This target review gate is not approval to send outreach. It only prepares the human review process for selecting and approving outreach targets.
