# Reviewer Start Here

Quantum Pi Forge is a sovereign AI/blockchain infrastructure prototype moving from narrative constellation to verifiable protocol surface.

This repository is the active public canon for reviewer orientation, claim classification, and proof routing.

## Review Standard

Do not rely on mythology first.

Run the evidence path first.

Every claim should be treated as one of:

- **Verifiable** — executable proof exists
- **Pending** — intended but not yet fully proven publicly
- **Disabled** — intentionally inactive until verification is complete
- **Archive** — historical context only
- **Aspirational** — direction of travel, not current operational fact

## Canonical Review Path

1. Read `docs/review/VERIFICATION_STATUS_TABLE_V1.md` (feature SSOT: Verified / Implemented but gated / Experimental / Planned)
2. Read `docs/review/CLAIM_TO_PROOF_MATRIX.md` (reviewer claim vocabulary)
3. Confirm which claims are verifiable, pending, disabled, archived, or aspirational
4. Run available local verification scripts
5. Compare public site claims against the status table and matrix (`docs/review/PUBLIC_SURFACE_CLAIM_AUDIT_V1.md`)
6. Treat disabled economic flows as safety boundaries, not failures
7. Treat grant/partner language as valid only if it derives from the status table (`docs/valuation/QPF_GRANT_PARTNER_OUTREACH_KIT_V1.md`)
