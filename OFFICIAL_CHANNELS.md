# Official Channels

This document defines the official public communication surfaces for Quantum Pi Forge.

## Canonical Sources

- Website: https://quantumpiforge.com
- GitHub: https://github.com/onenoly1010/Quantum-pi-forge

## Security Notice

Quantum Pi Forge does not conduct private sales, liquidity requests, wallet-connection campaigns, recovery requests, or airdrops through unsolicited direct messages.

Any claim, offer, contract address, funding request, or wallet interaction should be treated as unverified unless it is linked from the canonical website or canonical GitHub repository.

## Contact Policy

Public technical verification should happen through the canonical GitHub repository, issues, pull requests, or public documentation.

Do not trust screenshots, copied messages, unofficial mirrors, or direct-message instructions as authoritative.

## Contract Safety

Users should independently verify contract addresses and deployment evidence from canonical project sources before interacting with any on-chain component.
