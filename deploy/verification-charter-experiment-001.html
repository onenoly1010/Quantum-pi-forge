QPF One Public File · Verification Experiment #001

Charter

Purpose

Determine whether an independently reproducible verification system can confirm a public artifact exactly as published — using one public file and one precise claim from an external participant.

Classification

This is an experiment, not a service. Nothing is sold. No favorable result is promised or implied.

Intake

  • One public URL or public repository path.
  • One precise claim about that artifact (one sentence).

Method

  1. Fetch the public bytes at a recorded UTC timestamp T.
  2. Compute sha256 digest; run Level-0 deterministic verification (qpfv0: result id, qpfpkg0: package id).
  3. Issue an evidence package containing the claim, timestamp, digests, methods, findings, and limits.
  4. Anyone may re-fetch and re-derive against the pinned receipt forever.

Scope statement (appears in every result)

"We verified the content of the named file at the stated timestamp. We did not verify authorship, accuracy of statements within the document, legal effect, or anything about systems the document describes."

Outcome ledger

  • VERIFIED — evidence reproduces claim → case study #001.
  • NOT VERIFIED — filter rejects broken claim → proof of teeth.
  • SILENCE — recorded as OUTREACH_ATTEMPTED → NO_RESPONSE: adoption baseline, not failure.

Authority boundary

Read-only regarding participant systems. No credentials, accounts, uploads, wallets, signing, minting, transfers, deployments, or payment. Not a security audit, legal opinion, or investment advice. Economic lanes of Quantum Pi Forge remain locked throughout.
