Quantum Pi Forge / OINIO — canonical deployments on 0G Aristotle Mainnet

Purpose of this page

This page provides the canonical deployment addresses for Quantum Pi Forge components. Its purpose is to enable independent verification by allowing anyone to inspect deployed contracts, compare them with the published source code and registry documentation, and reproduce verification results.

Publication of deployment information does not imply that all protocol features are active. Features such as minting, liquidity, or other economic functionality remain subject to their own governance and authorization requirements—and are currently intentionally disabled.

Flow for reviewers: Architecture → Deployments (this page) → Verification → Independent reproduction → Governance decisions.
